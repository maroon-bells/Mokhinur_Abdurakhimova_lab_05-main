# Lab 05 glossary

| Term | Meaning in this lab |
|---|---|
| Source boundary | Exact point separating retained prose from headings/front matter/notes |
| NFC | Unicode form that composes equivalent accent sequences consistently |
| Literal match | A match to the stated spelling and boundary rules |
| Entity resolution | Deciding whether different references denote the same real person/object; not performed here |
| Denominator | The measured amount of text used to normalize counts |
| Cumulative sum | Total through the current chapter, along the chapter axis |
| Provenance | Origin, transformations, and interpretation limits of the data |
| Hash | Byte-level fingerprint used to detect a change to an input file |
| Long form | One row per chapter/name pair, with repeated chapter metadata |
| Operational definition | The exact rule used to turn a concept, such as a word, into a measurable count |
